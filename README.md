# Payment Processor Fee & Settlement Audit

Find processor pricing, reserve, and settlement errors and reconcile transaction-level cash to contractual economics.

**Primary buyer:** Enterprise merchants and platforms. **Evidence:** processing agreements, transaction logs, authorizations, captures, refunds, chargebacks, pricing tiers, gateway fees, reserves, settlements, and bank deposits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Processor agreement library
- Merchant account registry
- Authorization capture ingestion
- Refund chargeback ingestion
- Pricing model reconstruction
- Markup fee calculation
- Gateway fee validation
- Minimum fee control
- Reserve holdback reconciliation
- Settlement timing audit
- Deposit-to-batch matching
- Missing settlement detection
- Processor dispute workflow
- Cash recovery ledger
- Account processor analytics

Run `./start.sh`, then open <http://127.0.0.1:4668>. API: `5668`.
